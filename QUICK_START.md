## 1️⃣ Preparazione (30 secondi)

### Apri Browser
```
http://172.25.247.161:3000
```

### Pulisci Cache (se necessario)
Premi **F12** → Console:
```javascript
localStorage.clear()
```
Poi **F5**

---

## 2️⃣ Registrazione (30 secondi)

### Crea Account
1. Clicca "Register"
2. Compila:
   - Username: `demo`
   - Email: `demo@test.com`
   - Password: `Password123`
3. Clicca "Register"

✅ **Risultato**: Dashboard caricata!

---

## 3️⃣ Primo Task (1 minuto)

### Crea Task Base
1. Clicca "Nuovo Task"
2. Titolo: `Il mio primo task`
3. Clicca "Crea Task"

✅ **Risultato**: Task creato!

### Crea Task Completo
1. Clicca "Nuovo Task"
2. Compila:
   - **Titolo**: `Task avanzato`
   - **Tags**: Aggiungi `demo`, `test`
   - **Subtasks**: Aggiungi `Step 1`, `Step 2`, `Step 3`
   - **Scadenza**: Domani
   - **Priorità**: Alta
3. Clicca "Crea Task"

✅ **Risultato**: Task con tags, subtasks e progress bar!

## 🎯 Scenario Reale (5 minuti)

### Progetto: "Implementare Login"

**STEP 1**: Crea Task Principale
```
Titolo: Implementare sistema di login
Tags: #backend, #auth, #sprint1
Priorità: Alta
Scadenza: In 3 giorni
```

**STEP 2**: Aggiungi Subtasks
```
☐ Setup JWT library
☐ Create User model
☐ Implement register endpoint
☐ Implement login endpoint
☐ Add password hashing
☐ Write tests
```

**STEP 3**: Lavora sul Task
- Segna subtask completati man mano
- Vedi progress crescere
- Dashboard mostra avanzamento

**STEP 4**: Completa
- Segna ultimo subtask
- Cambia stato → "Completato"
- Dashboard aggiorna statistiche

✅ **Risultato**: Workflow completo tracciato!

## 🐛 Problemi Comuni

### "Impossibile caricare i task"
**Soluzione**:
```javascript
localStorage.clear()  // F12 → Console
```
Poi F5

### "Token expired"
**Soluzione**: Fai logout → login

### Backend non risponde
**Soluzione**: Verifica che sia running su porta 5000

### Frontend su porta sbagliata
**Soluzione**: Deve essere su `http://172.25.247.161:3000`
